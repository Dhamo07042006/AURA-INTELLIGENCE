1. SYSTEM ARCHITECTURE & OVERVIEW
----------------------------------------------------------------------------------------------------
The External Medical Equipment Log Generator is a standalone web application designed to run on a 
separate PC, server, or cloud instance. It simulates physical medical devices installed across hospital 
departments (ICU, Radiology, Clinical Lab, Operating Room) and streams live telemetry logs, sensor 
readings, error codes, and operational telemetry over HTTP REST API or MQTT / WebSockets into the 
central AURA platform.

Architecture Flow:
[ External Generator Machine ] ───( REST POST / MQTT )───► [ AURA Central Server: http://<IP>:8000 ]
  (Simulates Ventilators,                                     (Processes Live ML Inference, Digital Twins,
   Monitors, Scanners)                                         Alerts, SHAP, and RAG Advice)


2. CENTRAL AURA SERVER ENDPOINTS & CONNECTION PARAMETERS
----------------------------------------------------------------------------------------------------
Central Server Base URL: http://<AURA_SERVER_IP>:8000

A) REST Ingestion Endpoint:
   - URL    : POST http://<AURA_SERVER_IP>:8000/api/v1/ingest/telemetry
   - Headers: 
       Content-Type : application/json
       X-API-Key    : aura_live_ingest_key_2026
       Hospital-ID  : demo-hospital (or target hospital_id)

B) MQTT Broker Endpoint:
   - Host   : <AURA_SERVER_IP>
   - Port   : 1883
   - Topic  : hospital/demo-hospital/telemetry

C) WebSocket Real-time Endpoint:
   - URL    : ws://<AURA_SERVER_IP>:8000/api/v1/realtime/devices?token=<JWT_TOKEN>


3. EXACT TELEMETRY LOG JSON PAYLOAD SCHEMAS
----------------------------------------------------------------------------------------------------
Your external log generator website must output telemetry payloads in the following JSON format:

Example 1: Ventilator Log Payload
{
  "hospital_id": "demo-hospital",
  "device_id": "DEV000001",
  "device_type": "Ventilator",
  "department": "Intensive Care Unit (ICU)",
  "timestamp": "2026-08-15T23:30:00Z",
  "battery_health": 88.5,
  "temperature": 37.2,
  "load_percent": 65.0,
  "error_code": "OK",
  "operating_hours": 1420.5,
  "voltage": 23.8
}

Example 2: Patient Monitor Failure Log Payload (Battery Degradation Scenario)
{
  "hospital_id": "demo-hospital",
  "device_id": "DEV000005",
  "device_type": "Patient monitor",
  "department": "Intensive Care Unit (ICU)",
  "timestamp": "2026-08-15T23:30:05Z",
  "battery_health": 22.1,
  "temperature": 42.8,
  "load_percent": 92.0,
  "error_code": "BAT_CRITICAL",
  "operating_hours": 3800.0,
  "voltage": 18.2
}

Supported Error Codes for ML Anomaly Triggering:
- "OK"           : Normal operation
- "BAT_WARN"     : Low battery health warning
- "BAT_CRITICAL" : Critical battery failure risk
- "TEMP_WARN"    : Elevated component temperature
- "TEMP_CRITICAL": High thermal failure risk
- "SENSOR_ERR"   : Sensor calibration drift or failure
- "POWER_FLUC"   : Power supply voltage fluctuation
- "SYS_RESET"    : Microcontroller system reset event


4. REQUIRED EXTERNAL LOG GENERATOR WEBSITE USER INTERFACE FEATURES
----------------------------------------------------------------------------------------------------
When building the external log generator website UI, include the following controls:

1. Target Server Connection Panel:
   - Input Box: Central AURA Server IP / Host (e.g., 192.168.1.100 or localhost)
   - Input Box: Port (Default: 8000)
   - Input Box: Hospital ID (Default: demo-hospital)
   - Status Badge: Connected / Disconnected

2. Device Generator Controls:
   - Device Selector: DEV000001 to DEV009434
   - Device Type Dropdown: Ventilator, Patient monitor, CT scanner, MRI scanner, Infusion pump, EKG
   - Department Dropdown: Intensive Care Unit (ICU), Radiology, Clinical Lab, Operating Room

3. Failure Simulation Injector:
   - Normal Operation Mode (Randomized healthy telemetry)
   - Battery Degradation Mode (Gradually drops battery health to 15% and emits BAT_CRITICAL)
   - Thermal Overheating Mode (Ramps component temperature to 48°C and emits TEMP_CRITICAL)
   - Sensor Failure Mode (Injects random noise & SENSOR_ERR codes)
   - Power Instability Mode (Fluctuates voltage & emits POWER_FLUC)

4. Log Streaming Controls:
   - Interval Selector: 1 second, 3 seconds, 5 seconds, 10 seconds
   - Buttons: "Start Log Stream", "Pause Stream", "Inject Instant Failure Alert", "Stop Stream"
   - Live Raw Terminal Console: Auto-scrolling text console showing outgoing JSON HTTP requests


5. COMPLETE RUNNABLE STANDALONE PYTHON SCRIPT FOR SEPARATE SYSTEM
----------------------------------------------------------------------------------------------------
You can save the following standalone script as `external_hospital_log_generator.py` on ANY 
separate machine or laptop, install `requests`, and run it to stream live telemetry into AURA:

```python
import time
import json
import random
import datetime
import requests

# CONFIGURE TARGET CENTRAL AURA PLATFORM SERVER IP HERE
AURA_SERVER_IP = "127.0.0.1"  # Replace with actual IP of machine running AURA (e.g. 192.168.1.50)
AURA_PORT = "8000"
HOSPITAL_ID = "demo-hospital"

INGEST_URL = f"http://{AURA_SERVER_IP}:{AURA_PORT}/api/v1/ingest/telemetry"
API_KEY = "aura_live_ingest_key_2026"

DEVICES = [
    {"id": "DEV000001", "type": "Ventilator", "dept": "Intensive Care Unit (ICU)"},
    {"id": "DEV000002", "type": "Patient monitor", "dept": "Intensive Care Unit (ICU)"},
    {"id": "DEV000003", "type": "CT scanner", "dept": "Radiology Department"},
    {"id": "DEV000004", "type": "Infusion pump", "dept": "General Ward"},
    {"id": "DEV000005", "type": "ECG machine", "dept": "Clinical Laboratory"}
]

SCENARIOS = ["OK", "BAT_WARN", "BAT_CRITICAL", "TEMP_CRITICAL", "SENSOR_ERR", "POWER_FLUC"]

def generate_telemetry_log(device, force_scenario=None):
    scenario = force_scenario if force_scenario else random.choice(["OK", "OK", "OK", "OK", random.choice(SCENARIOS)])
    
    bat_health = round(random.uniform(75.0, 99.0), 1)
    temp = round(random.uniform(34.0, 38.0), 1)
    error = "OK"
    
    if scenario == "BAT_CRITICAL":
        bat_health = round(random.uniform(10.0, 25.0), 1)
        error = "BAT_CRITICAL"
    elif scenario == "TEMP_CRITICAL":
        temp = round(random.uniform(43.0, 52.0), 1)
        error = "TEMP_CRITICAL"
    elif scenario == "SENSOR_ERR":
        error = "SENSOR_ERR"
    elif scenario == "POWER_FLUC":
        error = "POWER_FLUC"

    payload = {
        "hospital_id": HOSPITAL_ID,
        "device_id": device["id"],
        "device_type": device["type"],
        "department": device["dept"],
        "timestamp": datetime.datetime.utcnow().strftime("%Y-%m-%dT%H:%M:%SZ"),
        "battery_health": bat_health,
        "temperature": temp,
        "load_percent": round(random.uniform(40.0, 95.0), 1),
        "error_code": error,
        "operating_hours": round(random.uniform(500.0, 5000.0), 1)
    }
    return payload

def main():
    print("==========================================================================")
    print(f"  EXTERNAL HOSPITAL MEDICAL LOG GENERATOR STARTING...")
    print(f"  Target Server: {INGEST_URL}")
    print(f"  Hospital ID  : {HOSPITAL_ID}")
    print("==========================================================================")

    headers = {
        "Content-Type": "application/json",
        "X-API-Key": API_KEY,
        "Hospital-ID": HOSPITAL_ID
    }

    step = 0
    while True:
        step += 1
        dev = random.choice(DEVICES)
        
        # Every 10th step, inject a simulated failure to trigger ML alerts
        scenario = "BAT_CRITICAL" if step % 10 == 0 else None
        log_payload = generate_telemetry_log(dev, force_scenario=scenario)

        try:
            res = requests.post(INGEST_URL, json=log_payload, headers=headers, timeout=3)
            if res.status_code == 200:
                data = res.json()
                print(f"[{datetime.datetime.now().strftime('%H:%M:%S')}] ✅ Streamed Log for {dev['id']} ({dev['type']}) ➔ Status: {data.get('status')} | Anomaly Score: {data.get('anomaly_score')}")
            else:
                print(f"[{datetime.datetime.now().strftime('%H:%M:%S')}] ⚠️ Server returned HTTP {res.status_code}: {res.text}")
        except Exception as e:
            print(f"[{datetime.datetime.now().strftime('%H:%M:%S')}] ❌ Connection Failed: {e}")

        time.sleep(3.0)  # Stream log every 3 seconds

if __name__ == "__main__":
    main()
```

        let timer = null;
        function log(msg) {
            const c = document.getElementById('console');
            c.innerHTML += '<div>[' + new Date().toLocaleTimeString() + '] ' + msg + '</div>';
            c.scrollTop = c.scrollHeight;
        }

        function startStreaming() {
            document.getElementById('startBtn').style.display = 'none';
            document.getElementById('stopBtn').style.display = 'block';

                const payload = {
                    hospital_id: hosp,

                        headers: {
                            'Content-Type': 'application/json',
                            'X-API-Key': 'aura_live_ingest_key_2026',
                            'Hospital-ID': hosp
                        },
                        body: JSON.stringify(payload)
                    });
                    const data = await res.json();
                    log('✅ Sent Log for ' + payload.device_id + ' | Server Response: ' + JSON.stringify(data));
                } catch(err) {
                    log('❌ Stream Error: ' + err.message);
                }
            }, 3000);
        }

        function stopStreaming() {
            clearInterval(timer);
            document.getElementById('startBtn').style.display = 'block';
            document.getElementById('stopBtn').style.display = 'none';
            log('Log stream stopped.');
        }
    </script>
</body>
</html>
